# Калькулятор окупаемости курса

Помесячная модель окупаемости онлайн-курса: два канала привлечения (своя база и реклама), воронка «регистрация → пришёл → заказ → оплата», разработка и дополнительные расходы. Все вводные задаются ползунками по месяцам, горизонт — от 3 до 12 месяцев. Есть сводка по трём сценариям, выгрузка в PDF и Excel; последние настройки запоминаются в браузере.

Калькулятор — один файл [`index.html`](index.html): его можно открыть в браузере или разместить на любом статическом хостинге (например, GitHub Pages). Для шрифтов и выгрузки PDF нужен интернет.

Стартовые значения взяты из финмодели курса «AI-кино» и служат примером.

[`prompt_course_roi_calculator.md`](prompt_course_roi_calculator.md) — промт, по которому Claude собирает такой калькулятор: логика расчёта, контрольные значения для самопроверки и требования к интерфейсу.
